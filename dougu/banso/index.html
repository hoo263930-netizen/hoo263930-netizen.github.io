伴走｜イベントができて、続いていくまで

イベント・教室・地域の会を開く人のための、AIの相棒です。

始めるところから、チラシ、記録、次の回まで付き合います。試作版を、無料で配っています。

無料でダウンロード

こんなときに

  • 新しく会を始めたいけれど、何から手をつければいいか分からない
  • 場所が見つからない。誰と一緒にやればいいか分からない
  • AIにチラシを頼んだら、ごちゃごちゃしたものが返ってきた
  • 会が終わったあと、何を残して、次にどう生かせばいいか分からない

活動は、場所（箱）・関わる人（ひと）・道具や連絡手段（もの）の3つがそろったとき、はじめて回り出します。伴走は、その土台の点検から、チラシ、記録、次の回の見直しまでを、AIと一緒にやるための手引きです。

伴走でできること

話しかける言葉によって、4つの場面で付き合います。質問はいつも一覧でまとめて出るので、音声入力で一気に答えられます。

始める

「新しい回を始めたい」

箱・ひと・ものを並べて、足りないところを見える化します。場所の候補をためておく台帳や、場所を借りるときの打診の叩き台も作ります。

チラシ

「チラシを作りたい」

19の質問に答えると、構成案（3案＋おすすめ）と、画像を作るAIに渡す指示文ができます。日時や金額は画像に描き込ませず、あとから入れる作りです。

記録

「回が終わったから記録したい」

誰が来たか、想定と違ったことを1枚に残します。箱・ひと・もの・マーケの4つで見て、次の一手を3案で出します。

相談

「相談したい」

人が集まらない、なんだかうまくいかない。過去の記録を読んでから、一緒に考えます。

デザインの画像そのものは作りません。画像は、ChatGPT・Canva など、お使いのもので作ります。

使い方

くわしくは、zipの中の README にあります。

Claude Code で使う

  1. zipを開いて、banso フォルダを .claude/skills の中へ、フォルダごと入れる
  2. 新しいチャットを開く
  3. 「新しい回を始めたい」「チラシを作りたい」などと話しかける

ChatGPT で使う

  1. 「プロジェクト」を新しく作る
  2. プロジェクトの「ファイル」に chatgpt/伴走.md を入れる
  3. 「指示」の欄に、READMEにある1行を貼る
  4. そのプロジェクトの中で、同じように話しかける

使うには、Claude Code（Anthropic の有料プラン）か、ChatGPT の「プロジェクト」の機能が要ります。ChatGPTでは、記録や場所の台帳は会話の中に表で出てきます。手元のメモなどに保存しておき、次に相談するときに貼ってください。
