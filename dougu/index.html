地域の道具

何か始めたいけど、重く考えて動けない方へ 滋賀県高島市の会で実際に使っている道具と、会の始め方を、無料で置いています 小さく始めて、続けるかは1回やってから決める。ひとりで回せる形です

地域で、だれでも使える道具をつくっています。

遊べるお寺プロジェクトは、地域のつながりを広げるために、いろいろな会を開いています。その中から生まれた「みんなが自分で使える道具」を、ここにまとめています。使い方を覚えたら、あとはご自分の会や地域で、自由に使ってください。

たかしまーじゃん

牌だけあればOK。3〜5人で遊べる、新しい麻雀です。初級・中級・上級と、少しずつステップアップできます。ルール資料は無料で、自由にコピーして使えます。

チラ置き（高島のイベントチラシ置き場）

高島の講座・イベント・集まりのチラシを、スマホでカレンダーのように見られるページです。チラシを載せるのも、見るのも無料・登録なし。合言葉「たかしま」で、だれでも自分の会の案内を載せられます。

AIの相棒・試作版・2026年10月

地域の会・教室・イベントを開く人のための、AIの手引き。始める・チラシ・記録・相談の4つの場面で付き合います。Claude Code と ChatGPT で使えます。

集まりで使える おみくじ

はじめて会う人どうしでも、話しやすくなるおみくじです。会のはじめの「ひとことずつ」に。

ことばみくじ

筒をタップすると、仏教のことばの札が1枚出ます。札には、ことばと読みがな、やさしい意味、話すための問い。吉・凶はありません。引いた人が問いに答えて、ほかの人も同じ問いで話します。ことばは20個です。

ことばみくじを開く

おしゃべりおみくじ

筒をタップすると、質問の札が1枚出ます。「最近、ハマっているものは？」のような、だれでも答えやすい質問です。1周目の筒と、少し考える質問の2周目の筒があります。はじめて会う人どうしの自己紹介に。

おしゃべりおみくじを開く

使い方：iPadやスマホを机のまん中に置いて、順番に引きます。登録なし・無料で、だれでも使えます。

iPadやiPhoneのSafariで「共有」→「ホーム画面に追加」をすると、アプリのように全画面で開けます。引いた札は、同じ画面を開いているあいだは覚えています（「最初から」で筒に戻せます）。

使い方で分からないことは、全国版LINEの「こーせんAIに聞く」から（無料・1日10回まで）
